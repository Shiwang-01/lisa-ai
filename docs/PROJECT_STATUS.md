## 🔒 Scope Policy Under Code Freeze

The release `v1.0.0-prototype` represents a stable, frozen evaluation checkpoint.

### Currently Allowed:
- Public repository visibility & publication management
- Documentation updates, links, and formatting
- Presentation pitch deck creation & slide design

### Strictly Prohibited (Requires a New Major/Minor Version):

- Heuristic curve, score weight, or threshold modifications
- UI layout redesign or cosmetic component changes

- Dependency additions or major package upgrades

- Synthetic dataset schema or fixture modifications
